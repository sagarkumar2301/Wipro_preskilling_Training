# HR Management & Workforce Analytics

## Project Overview
HR Management & Workforce Analytics is an ASP.NET Core MVC application used to manage employees and leave requests.

## Features
- Employee Management (CRUD)
- Leave Request Management
- Leave Approval / Rejection
- Audit Logs
- Dashboard Analytics
- JWT Authentication
- Role-Based Authorization
- Web API with Swagger
- Search & Filter
- Export to Excel

## Technologies Used
- ASP.NET Core MVC (.NET 8)
- Entity Framework Core
- SQL Server
- JWT Authentication
- Swagger
- GitHub Actions
- Docker

## How to Run
1. Clone repository
2. Update connection string
3. Run migrations
4. Execute application
