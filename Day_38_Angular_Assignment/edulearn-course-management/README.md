# EduLearn Course Management

## Project Description

This project is a simple Angular Single Page Application (SPA) for managing courses.

## Features

- Display list of courses
- View selected course details
- Edit course title dynamically
- Real-time UI updates

## Angular Concepts Used

### Property Binding

Used to pass course data from parent component to child component.

Examples:

```html
[courses]="courses"
[course]="selectedCourse"
